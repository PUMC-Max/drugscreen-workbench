# Contributing

Use synthetic or explicitly shareable data in issues and pull requests. Do not attach private plate maps, readouts, databases, patient information or credentials.

Keep analysis functions independent of UI where possible. Explain units, sign conventions, reference controls and undefined cases for every new metric. Do not change an existing metric silently. Add behavioral tests and run the test suite; GUI tests require Tk and a display.

Bug reports should include the Python/OS versions, the chosen metric, steps to reproduce, and a minimal synthetic fixture. For new scientific methods, include a primary reference and the assumptions required by the design.
